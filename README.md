# Block-ChainTokenMarket
This project implements a smart contract using ERC20, written in the solidity language and is an exchange for trading tokens. 
Logic:
Addresses are divided into a token address, which has its own balance and sets the price for its token, and a buyer address, which can buy multiple tokens and store/view its tokens.
The Smart-Contrast.sol file contains the code of the contract itself, which is proposed to be inserted and run on the site. https://remix.ethereum.org /.
The gethProject folder contains all the data for launching the Etherium LAN.
